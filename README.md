# AO Ironman Season 12 — Field Manual

Getting-started guide for Anarchy Online Ironman Season 12 on RK19.

**Live page:** https://rad-talent.github.io/AOIM-S12/

Covers the ruleset, what infrastructure is locked at the drop, the cap schedule, level-filtered shop-roll and quest lists, and a pocket boss / symbiant lookup.

Mission specifics are deliberately not included — open Iron Questie to see what's available to you, and watch #announcements.

## Editing

All content lives in `data/` as JSON. Change a file there and the page updates — no HTML edits needed.

| File | What it holds |
|---|---|
| `status.json` | Locked/unlocked board, tradeskill cap, current cap, cap schedule |
| `rolls.json` | Shop roll windows by level |
| `quests.json` | Quest start levels |
| `pocketbosses.json` | Pocket bosses, their symbiants and pattern mobs |
| `shop.json` | Iron Coin Shop |
| `equipment.json` | Special equipment list |

Unofficial. Compiled from #challenges-rules, #season-information, #announcements, the Season 12 primer, and #resources threads by Tempzz, Code and Douk. Pocket boss data from ao.tinkeringidiot.com. Iron Questie is the source of truth once the season opens.
